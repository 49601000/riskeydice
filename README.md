# 仮想リスキーダイス

## 概要

ブラウザで動く、ミニマルな「リスキーダイス」アプリです。  
1回ごとに1〜20の乱数を引き、結果を次の2パターンで表示します。

- `1`: 大凶
- `2〜20`: 大吉

## ルール

- 1クリックで1回ロール（1d20相当）
- 大凶は `1/20`（5%）、大吉は `19/20`（95%）
- ロール累計と、大吉/大凶の回数を画面下に表示

表示例:

`12回中　大吉 1　大凶 2`

## 機能

- ダークトーンのシンプルUI
- 結果テキストのフェードインアニメーション
- 大凶時の強調表示（文字色・ボタン色を赤系に変更）
- ページリロードまでのセッション内でカウント継続

## 使い方

1. `index.html` をブラウザで開く
2. 「サイコロを / 振る」（2行表示）ボタンを押す
3. 中央カードに結果が表示され、下部に累計が更新される

## 技術仕様

- HTML5
- CSS3（アニメーション含む）
- JavaScript（`Math.random()`による疑似乱数）
- Google Fonts: `Noto Serif JP`

## 注意点

- 乱数は暗号学的用途向けではありません（`Math.random()`を使用）
- カウントはメモリ保持のみのため、リロードでリセットされます
- Google Fonts読込のため、初回表示時はネット接続が必要です
