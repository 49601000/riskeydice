# リスキーダイスシミュレーター

## 概要

このプロジェクトは、ブラウザ上でダイスロールをシミュレートするシンプルなウェブアプリケーションです。TRPGやボードゲームで使用するダイスを仮想的に振ることができます。

## 機能

- **ダイス設定**: ダイスの個数（1〜100個）と面数（2〜200面）を自由に設定可能
- **プリセット**: よく使うダイス設定（1d4, 1d6, 2d6 など）をワンクリックで選択
- **ロール結果**: 各ダイスの出目と合計値を表示
- **視覚効果**: ロール時のアニメーションと結果のハイライト（最大値/最小値）
- **キーボード操作**: Enterキーでロール可能

## 使い方

1. `index.html` をブラウザで開きます。
2. ダイスの個数と面数を入力またはプリセットボタンから選択します。
3. 「ROLL」ボタンをクリックするか、Enterキーを押してダイスを振ります。
4. 結果が画面に表示されます。

## 技術仕様

- **HTML5**: 構造とコンテンツ
- **CSS3**: スタイリングとアニメーション
- **JavaScript (ES6)**: ロジックとインタラクション

## ブラウザ対応

- モダンなブラウザ（Chrome, Firefox, Safari, Edge）で動作します。
- インターネット接続は不要です（オフラインで動作）。
